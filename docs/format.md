# Как читается репозиторий Ubuntu

Программа получает сам индекс Packages по HTTP или HTTPS.
Используются urllib, gzip и lzma из стандартной библиотеки Python.
APT и сторонние библиотеки для извлечения зависимостей не вызываются.

Адрес по умолчанию:
https://archive.ubuntu.com/ubuntu/dists/noble/main/binary-amd64/Packages.xz

Это конкретный индекс Ubuntu 24.04 для amd64, компонент main.
Можно передать другой индекс Packages, Packages.gz, Packages.xz.
Можно передать папку индекса: программа добавит Packages.xz.
Главная страница сайта репозитория сама по себе индексом не является.

Учитываются Depends и Pre-Depends. Recommends и Suggests не включаются.
Версии сохраняются в описании прямых зависимостей, но не решаются:
это просмотр объявленных связей, а не подбор плана установки.

В записи aa | bb показываются обе альтернативы. Это не означает,
что для установки одновременно требуются оба пакета.
У виртуального пакета добавляются связи ко всем его поставщикам
из Provides. Если имя совпадает с обычным пакетом, используется
обычный пакет. Архитектурные суффиксы, например :any, снимаются.
Анализ относится к одной архитектуре выбранного индекса.

Не найденные в индексе зависимости остаются листьями графа.
Они могут быть из другого компонента репозитория или архитектуры.
Несколько записей одного пакета не объединяются: программа просит
использовать один индекс с одной версией каждого пакета.
Синтаксис ограничений архитектуры из исходных Build-Depends
не поддерживается: здесь читается индекс готовых бинарных пакетов.

Формат полей описан в первоисточниках:

- https://www.debian.org/doc/debian-policy/ch-controlfields.html
- https://www.debian.org/doc/debian-policy/ch-relationships.html
