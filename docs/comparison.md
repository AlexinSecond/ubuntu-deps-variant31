# Сравнение с apt-cache

СТАТУС ПРОВЕРКИ

На Windows проверены собственные графы bash, grep и sed на настоящем
индексе Ubuntu 24.04, main, amd64. Установленного Ubuntu/WSL здесь нет.
Поэтому запуск apt-cache ещё не выполнен. Ниже подготовлена процедура
сравнения; её результат нельзя выдавать за уже проведённую проверку.

КАК ВЫПОЛНИТЬ СРАВНЕНИЕ

В Ubuntu должны быть python3, apt-cache и Graphviz. Откройте терминал
в папке проекта и выполните:

    sh scripts/compare_apt.sh

В WSL доступ к папке на диске C, например, выглядит так:

    cd /mnt/c/Users/etadl/Desktop/practice2-variant31/ubuntu-deps-variant31
    sh scripts/compare_apt.sh

Если Graphviz не установлен в Ubuntu, его устанавливают командой
sudo apt install graphviz. Сам проект использует только Python stdlib.

Скрипт сохраняет отдельный индекс Packages в output/apt-comparison.
Он настраивает apt-cache на этот индекс и пустой список установленных
пакетов. Системные источники и установленные пакеты не изменяются,
права администратора для самого сравнения не требуются.

Для каждого из трёх пакетов выполняются:

    apt-cache depends --important ИМЯ
    apt-cache -o APT::Cache::GivenOnly=true dotty ИМЯ

В скрипте к ним добавлены пути к отдельному индексу, чтобы обе программы
сравнивали Ubuntu noble/main/amd64, без примеси updates и security.
Далее Graphviz создаёт рисунок APT, наша программа — свой рисунок
с глубиной 1. Проверяются прямые зависимости и их наличие в DOT APT.

При успешной проверке появится файл comparison.txt со строками
direct dependencies match для bash, grep и sed.
Если сравнение выявит различие, скрипт завершится с ошибкой,
а исходные результаты останутся в output/apt-comparison для разбора.

ОЖИДАЕМЫЕ ПРЯМЫЕ ЗАВИСИМОСТИ

- bash: base-files, debianutils, libc6, libtinfo6.
- grep: libc6, libpcre2-8-0.
- sed: libacl1, libc6, libselinux1.

Это результат чтения указанного индекса нашей программой.
Фактическое совпадение со штатным apt-cache подтверждается только
после успешного выполнения скрипта на Ubuntu.

ПОЧЕМУ РИСУНКИ МОГУТ ВЫГЛЯДЕТЬ ПО-РАЗНОМУ

APT dotty различает типы узлов формой и показывает дополнительные типы
связей. Наш рисунок объединяет Depends и Pre-Depends и не включает
Recommends, Suggests, Conflicts и Breaks.
Для проверки совпадения используются обязательные прямые зависимости.
Дополнительные цели рёбер DOT APT перечисляются в comparison.txt.

Наша программа показывает все альтернативы и виртуальных поставщиков.
Она не выбирает версии и не строит план установки, учитывающий уже
установленные пакеты. У APT есть сведения о версиях и состоянии системы.
Также на обычном компьютере APT может использовать другие компоненты,
обновления или архитектуры. Поэтому сравнение сделано на отдельном индексе.

Порядок узлов, цвета и расположение стрелок не обязаны совпадать.
Нужно сравнивать сами связи и выбранную глубину.
