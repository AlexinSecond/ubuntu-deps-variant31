# Практическая работа 2. Вариант 31

Просмотр зависимостей пакетов Ubuntu на Python.
Программа читает индекс Packages, обходит зависимости и создаёт рисунок.
Работает в Windows, Linux и macOS. Python 3.10+, без сторонних библиотек.
Для PNG нужен Graphviz. Это отдельная программа для рисования графов.

БЫСТРЫЙ ЗАПУСК

Откройте PowerShell в этой папке и выполните:

    .\run.bat --package A --repo examples/tree.json --test-repo --ascii

Если Python не найден, укажите путь к своему Python и повторите запуск:

    $env:PYTHON_EXE = "C:\Users\etadl\AppData\Local\Programs\Python\Python314\python.exe"

Результат: дерево A -> B -> D и A -> C, файлы output/graph.dot и graph.png.

    Invoke-Item .\output\graph.png

В комплекте работы есть переносной Graphviz в соседней папке tools.
Если скачан только Git-репозиторий, установите Graphviz и добавьте его
в PATH или задайте GRAPHVIZ_DOT как полный путь к dot.exe.
Скачать: https://graphviz.org/download/

НАСТОЯЩИЙ ПАКЕТ

    .\run.bat --package bash --max-depth 2 --ascii --output output/bash.png

Нужен интернет. По умолчанию используется Ubuntu 24.04, main, amd64.
Программа не устанавливает пакеты и не меняет исходные данные.
Она выводит результат и завершается: команд ls и exit здесь нет.

ПАРАМЕТРЫ

--package: имя пакета, обязательно.
--repo: URL индекса Packages, Packages.gz, Packages.xz или его папки.
В учебном режиме это путь к JSON-файлу.
--test-repo: включить учебный режим без интернета.
--output: имя PNG, по умолчанию output/graph.png.
--ascii: дополнительно вывести текстовое дерево.
--max-depth: глубина 0..100, по умолчанию 3.
--exclude: исключить имена с указанной подстрокой, регистр важен.
--help: показать справку.

Флаги --test-repo и --ascii вводятся без значений yes или true.
Глубина 0 — только корень; 1 — прямые зависимости; 2 — следующий уровень.
Входной JSON содержит имена большими латинскими буквами, например:

    {"A": ["B"], "B": []}

КАК ПРОВЕРИТЬ

    .\test.bat
    .\scripts\demo_test.bat
    .\scripts\demo_real.bat

В конце тестов должно быть OK. В демонстрациях появятся рисунки в output.
Первая демонстрация проверяет циклы, глубину, фильтр и общие зависимости.
Вторая создаёт рисунки трёх настоящих пакетов: bash, grep, sed.
Сборка не требуется. В Linux: sh run.sh и python3 -m unittest discover -s tests -v.
Для реальных демонстраций в Linux: sh scripts/demo_real.sh.

ЧТО УЧИТЫВАЕТСЯ

Берутся Depends и Pre-Depends. Альтернативы показываются обе.
Виртуальные пакеты связаны с их поставщиками. Недостающие пакеты — листья.
Это граф объявленных зависимостей, а не подбор версий для установки.
Ограничения и формат подробно описаны в docs/format.md.

КОД

src/config.py — настройки и проверки.
src/download.py — скачивание и распаковка индекса.
src/packages.py — извлечение зависимостей без APT и сторонних библиотек.
src/repository.py — чтение учебного JSON и выбор источника.
src/graph.py — рекурсивный DFS, глубина и фильтр.
src/reverse.py — обратные связи для версии stage4.
src/visualize.py — DOT, PNG и текстовое дерево.
src/__main__.py — запуск и обработка ошибок.
tests — автоматические проверки. examples — учебные графы.

ЭТАПЫ

stage1 — параметры; stage2 — прямые зависимости; stage3 — DFS;
stage4 — обратные зависимости; stage5 — визуализация обычных зависимостей.
Каждый этап сохранён отдельным Conventional/Scoped-коммитом и меткой Git.
В комплекте также есть независимые копии stages/stage1 ... stages/stage5.
Их проще показывать без переключения Git. Финальная версия — main.
